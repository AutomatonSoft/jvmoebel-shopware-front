# `jv-hero`

Hero banner carousel for the main CMS page.

## `slot.data`

```json
{
  "ariaLabel": "Aktuelle Angebote und Wohnideen",
  "autoplay": true,
  "autoplayIntervalMs": 6500,
  "slides": [
    {
      "id": "living-room",
      "position": 0,
      "layout": "featured",
      "title": "Wohnzimmer, die sich nach Ihnen anfühlen.",
      "url": "/Moebel-Wohnen/Wohnzimmer/",
      "eyebrow": "Neue Wohnideen",
      "description": "Entdecken Sie ausgewählte Möbel für Ihr Zuhause.",
      "image": {
        "url": "https://media.example.com/hero/living-room.webp",
        "alt": "Helles Wohnzimmer mit Sofa"
      },
      "promotion": {
        "label": "Ausgewählte Kollektionen",
        "value": "Bis zu 20 %"
      },
      "primaryLink": {
        "label": "Wohnzimmer entdecken",
        "url": "/Moebel-Wohnen/Wohnzimmer/",
        "size": "large"
      },
      "secondaryLink": {
        "label": "Alle Möbel",
        "url": "/moebel-sortiment",
        "size": "medium"
      }
    }
  ]
}
```

## Field contract

Top-level fields:

| Field                | Required | Rule                                                                              |
| -------------------- | -------- | --------------------------------------------------------------------------------- |
| `slides`             | yes      | Array or keyed object containing at least one valid slide.                        |
| `ariaLabel`          | no       | Non-empty accessible carousel label.                                              |
| `autoplay`           | no       | `false` or `0` disables autoplay; every other value enables it. Default: enabled. |
| `autoplayIntervalMs` | no       | Finite number rounded and clamped to `4000`–`15000`. Default: `7000`.             |

Each slide:

| Field             | Required      | Rule                                                           |
| ----------------- | ------------- | -------------------------------------------------------------- |
| `position`        | yes           | Unique non-negative integer. Slides are sorted by this value.  |
| `title`           | yes           | Non-empty string.                                              |
| `image.url`       | yes           | Non-empty media URL.                                           |
| `id`              | no            | Stable identifier; generated by the frontend when omitted.     |
| `layout`          | no            | `featured` or `caption`; every other value becomes `featured`. |
| `url`             | no            | Makes the whole slide clickable.                               |
| `eyebrow`         | no            | Short text above the title.                                    |
| `description`     | no            | Supporting text.                                               |
| `image.alt`       | no            | Defaults to an empty string.                                   |
| `promotion.value` | conditionally | Required when `promotion` is provided.                         |
| `promotion.label` | no            | Context displayed with the promotion value.                    |
| `primaryLink`     | no            | Rendered when both `label` and `url` are valid.                |
| `secondaryLink`   | no            | Rendered when both `label` and `url` are valid.                |

Link `size` accepts `small`, `medium`, or `large` and defaults to `medium`.
Arrays are canonical; keyed slide objects are also accepted. The legacy
single-slide payload at the root remains supported, but new Administration
integrations should always emit `slides`.

Invalid slides are omitted. A missing, invalid, or duplicate `position` makes
that slide invalid. The whole element is omitted when no valid slides remain.
Autoplay pauses during hover or focus and respects reduced-motion preferences.

## Shopware Administration

Register the `jv-hero` element and block. Editors should be able to add,
remove, reorder, and configure slides; choose media; select the layout and
button sizes; set links and promotion copy; and control carousel autoplay.
The resolver must convert selected media to `{ "url", "alt" }` and assign a
unique numeric `position` to every slide.
