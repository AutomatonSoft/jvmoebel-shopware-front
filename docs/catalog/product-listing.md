# Каталог товаров

## Назначение

`/moebel-sortiment` — специальная витринная страница с фильтрами, сортировкой и пагинацией. Это не обычная Shopping Experience: её интерфейс и параметры запроса принадлежат frontend, а товары и агрегаты поступают из Shopware Store API.

## URL-параметры

| Параметр               | Назначение                                                                |
| ---------------------- | ------------------------------------------------------------------------- |
| `category`             | Один или несколько идентификаторов категорий через запятую.               |
| `manufacturer`         | Один или несколько идентификаторов производителей через запятую.          |
| `property`             | Один или несколько идентификаторов свойств через запятую.                 |
| `minPrice`, `maxPrice` | Нижняя и верхняя границы цены.                                            |
| `sort`                 | `featured`, `newest`, `price-ascending`, `price-descending` или `rating`. |
| `page`                 | Положительный номер страницы; по умолчанию `1`.                           |

## Источник данных

- В mock-режиме сервер использует локальный fixture и применяет те же фильтры, сортировку и пагинацию.
- В live-режиме сервер вызывает `POST /store-api/product-listing/{navigationCategoryId}`. В запрос передаются фильтры, сортировка, пагинация и агрегации категорий, производителей и свойств.
- Цены, медиа, SEO URL, свойства и производитель нормализуются в frontend-модель интеграционным слоем; CMS не определяет набор товаров.

## Граница ответственности

Shopware управляет товарами, доступностью в sales channel, ценами, медиа, свойствами, производителями и SEO URL. Frontend управляет интерфейсом фильтров, допустимыми параметрами URL и отображением результатов.
