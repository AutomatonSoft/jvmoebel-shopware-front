# `jv-subcategory-links`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Сетка ссылок на подкатегории.

## Настройка в Shopware

| Поле            | Где отображается             | Обязательно |
| --------------- | ---------------------------- | ----------- |
| Заголовок       | Над сеткой                   | Да          |
| Название ссылки | Текст пункта                 | Да          |
| Ссылка          | Переход при нажатии на пункт | Да          |
| Порядок         | Последовательность ссылок    | Нет         |

## Технический контракт Shopware

- `slot.type`: `jv-subcategory-links`; данные передаются в `slot.data`.

| Поле                             | Тип                | Правило                                 |
| -------------------------------- | ------------------ | --------------------------------------- |
| `title`                          | `string`           | Непустая строка.                        |
| `links`                          | `array \| object`  | Хотя бы одна корректная ссылка.         |
| `links[].label`, `links[].url`   | `string`           | Непустые строки.                        |
| `links[].id`, `links[].position` | `string \| number` | Необязательны; position задаёт порядок. |

Некорректные ссылки пропускаются; без корректных ссылок элемент не рендерится.
