# `product-listing`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Стандартный элемент Shopware для вывода каталога товаров на странице категории.

## Настройка в Shopware

У элемента нет редактируемых полей. Разместите его в layout страницы категории: он выводит товары, выбранные самой категорией и её правилами листинга.

## Технический контракт Shopware

- `slot.type`: `product-listing`.
- `slot.data` и `slot.config` не используются.
- Данные передаются не из CMS-слота, а маршрутом страницы в `renderContext.categoryListing`.

| Данные            | Источник                                           | Правило                                             |
| ----------------- | -------------------------------------------------- | --------------------------------------------------- |
| `categoryListing` | Store API и серверный загрузчик страницы категории | Обязательный объект листинга для текущей категории. |

Если маршрут не передал `categoryListing`, элемент не рендерится и сервер регистрирует ошибку рендеринга.
