# `jv-chip-rail`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Горизонтальный список быстрых ссылок в виде чипов.

## Настройка в Shopware

| Поле         | Где отображается         | Обязательно |
| ------------ | ------------------------ | ----------- |
| Заголовок    | Над списком чипов        | Да          |
| Надзаголовок | Над заголовком           | Нет         |
| Текст чипа   | Текст ссылки             | Да          |
| Ссылка чипа  | Переход при нажатии      | Да          |
| Порядок      | Последовательность чипов | Нет         |

## Технический контракт Shopware

- `slot.type`: `jv-chip-rail`; данные передаются в `slot.data`.

| Поле                           | Тип               | Правило                                                                  |
| ------------------------------ | ----------------- | ------------------------------------------------------------------------ |
| `title`                        | `string`          | Непустая строка.                                                         |
| `eyebrow`                      | `string`          | Необязательный надзаголовок.                                             |
| `chips`                        | `array \| object` | Хотя бы один корректный чип; массив является основным форматом.          |
| `chips[].label`, `chips[].url` | `string`          | Непустые строки.                                                         |
| `chips[].position`             | `number`          | Необязателен; сортирует чипы, иначе используется порядок входных данных. |
| `chips[].id`                   | `string`          | Необязателен; иначе формируется из текста и позиции.                     |

Некорректные чипы пропускаются; без корректных чипов элемент не рендерится.
