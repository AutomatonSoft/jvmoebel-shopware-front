# `jv-countdown-promo`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Промо-блок с обратным отсчётом, описанием акции, кнопкой и необязательным промокодом.

## Настройка в Shopware

| Поле                    | Где отображается         | Обязательно |
| ----------------------- | ------------------------ | ----------- |
| Заголовок               | Основной текст акции     | Да          |
| Дата окончания          | Таймер обратного отсчёта | Да          |
| Надзаголовок и описание | Над и под заголовком     | Нет         |
| Текст и ссылка кнопки   | Кнопка действия          | Да          |
| Промокод                | Плашка рядом с кнопкой   | Нет         |

## Технический контракт Shopware

- `slot.type`: `jv-countdown-promo`; данные передаются в `slot.data`.

| Поле                                  | Тип                        | Правило                                           |
| ------------------------------------- | -------------------------- | ------------------------------------------------- |
| `title`                               | `string`                   | Непустая строка.                                  |
| `endsAt`                              | `string`                   | Допустимая дата-время, распознаваемая JavaScript. |
| `link.label`, `link.url`              | `string`                   | Обе непустые строки обязательны.                  |
| `link.size`                           | `small \| medium \| large` | Необязателен, по умолчанию `medium`.              |
| `eyebrow`, `description`, `promoCode` | `string`                   | Необязательные тексты.                            |

При отсутствии заголовка, срока или корректной ссылки элемент не рендерится.
