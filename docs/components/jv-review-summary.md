# `jv-review-summary`

## Скриншот

![Скриншот Component](./screenshots/jv-review-summary.png)

## Назначение

Краткий блок с цитатой из отзыва, источником и оценкой по пятибалльной шкале.

## Настройка в Shopware

| Поле         | Где отображается      | Обязательно |
| ------------ | --------------------- | ----------- |
| Текст отзыва | Основная цитата       | Да          |
| Источник     | Над цитатой           | Да          |
| Оценка       | Число и звёзды справа | Да          |

## Технический контракт Shopware

- `slot.type`: `jv-review-summary`; данные передаются в `slot.data`.

| Поле                     | Тип      | Правило                                                    |
| ------------------------ | -------- | ---------------------------------------------------------- |
| `summary`, `sourceLabel` | `string` | Непустые строки.                                           |
| `rating`                 | `number` | Число от `0` до `5` включительно; число звёзд округляется. |

При невалидном значении оценки или отсутствии текста элемент не рендерится.
