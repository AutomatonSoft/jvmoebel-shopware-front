# `text`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Стандартный блок форматированного текста: абзацы, заголовки, списки, ссылки, цитаты и таблицы.

## Настройка в Shopware

Заполните поле текста стандартного CMS-элемента Shopware. Используйте редактор форматированного текста; потенциально опасные HTML-теги и атрибуты витрина удалит перед выводом.

## Технический контракт Shopware

- `slot.type`: `text`.
- Предпочтительный источник: `slot.data.content`.
- Для стандартного статического значения поддерживается `slot.config.content`.

| Поле                    | Тип      | Правило                                                              |
| ----------------------- | -------- | -------------------------------------------------------------------- |
| `data.content`          | `string` | Непустая HTML-строка; имеет приоритет.                               |
| `config.content.source` | `static` | Только для резервного статического значения.                         |
| `config.content.value`  | `string` | Непустая HTML-строка, используется, если `data.content` отсутствует. |

После санитизации должен остаться непустой контент; иначе элемент не рендерится и ошибка контракта регистрируется на сервере.
