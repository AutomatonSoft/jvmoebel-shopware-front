# `jv-inline-product-teaser`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Небольшая карточка товара внутри редакционного материала.

## Настройка в Shopware

| Поле                    | Где отображается              | Обязательно |
| ----------------------- | ----------------------------- | ----------- |
| Идентификатор товара    | Техническая привязка к товару | Да          |
| Название                | Заголовок карточки            | Да          |
| Описание                | Текст под названием           | Нет         |
| Изображение и alt-текст | Изображение товара            | Да          |
| Текст и ссылка кнопки   | Кнопка перехода к товару      | Да          |

## Технический контракт Shopware

- `slot.type`: `jv-inline-product-teaser`; данные передаются в `slot.data`.

| Поле                     | Тип                        | Правило                                     |
| ------------------------ | -------------------------- | ------------------------------------------- |
| `productId`, `name`      | `string`                   | Непустые строки.                            |
| `description`            | `string`                   | Необязательный текст.                       |
| `image.url`              | `string`                   | Непустой публичный URL.                     |
| `image.alt`              | `string`                   | Необязателен; по умолчанию название товара. |
| `link.label`, `link.url` | `string`                   | Обе непустые строки обязательны.            |
| `link.size`              | `small \| medium \| large` | Необязателен, по умолчанию `medium`.        |

`productId` сейчас нужен для идентификации, а карточка открывает `link.url`. При невалидных обязательных полях элемент не рендерится.
