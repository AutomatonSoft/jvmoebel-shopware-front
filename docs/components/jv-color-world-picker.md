# `jv-color-world-picker`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Сетка карточек цветовых миров с изображением и переходом в соответствующую подборку.

## Настройка в Shopware

| Поле                    | Где отображается            | Обязательно    |
| ----------------------- | --------------------------- | -------------- |
| Заголовок и описание    | Над карточками              | Заголовок — да |
| Название цвета          | Под изображением карточки   | Да             |
| Цвет                    | Круглый цветовой маркер     | Да             |
| Изображение и alt-текст | Основная часть карточки     | Да             |
| Ссылка                  | Карточка целиком            | Да             |
| Порядок                 | Последовательность карточек | Нет            |

## Технический контракт Shopware

- `slot.type`: `jv-color-world-picker`; данные передаются в `slot.data`.

| Поле                                                     | Тип                | Правило                                                                  |
| -------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------ |
| `title`                                                  | `string`           | Непустая строка.                                                         |
| `description`                                            | `string`           | Необязательный текст.                                                    |
| `colors`                                                 | `array \| object`  | Хотя бы одна корректная карточка.                                        |
| `colors[].name`, `colors[].url`                          | `string`           | Непустые строки.                                                         |
| `colors[].hex`                                           | `string`           | Корректный HEX: `#RGB`, `#RGBA`, `#RRGGBB` или `#RRGGBBAA`.              |
| `colors[].image.url`                                     | `string`           | Непустой публичный URL.                                                  |
| `colors[].image.alt`, `colors[].id`, `colors[].position` | `string \| number` | Необязательны; alt по умолчанию равен названию, position задаёт порядок. |

Некорректные карточки пропускаются; без корректных карточек элемент не рендерится.
