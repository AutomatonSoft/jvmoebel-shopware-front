# `jv-offer-rail`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Горизонтальная карусель рекламных предложений с изображениями, кнопками и необязательным таймером.

## Настройка в Shopware

| Поле                               | Где отображается               | Обязательно    |
| ---------------------------------- | ------------------------------ | -------------- |
| Заголовок, надзаголовок и описание | Над карточками                 | Заголовок — да |
| Название предложения               | Заголовок карточки             | Да             |
| Подзаголовок                       | Текст над названием            | Нет            |
| Изображение и alt-текст            | Изображение карточки           | Да             |
| Текст CTA и ссылка                 | Кнопка карточки                | Да             |
| Дата окончания                     | Таймер на карточке             | Нет            |
| Юридический текст                  | Мелкий текст карточки          | Нет            |
| Порядок                            | Последовательность предложений | Нет            |

## Технический контракт Shopware

- `slot.type`: `jv-offer-rail`; данные передаются в `slot.data`.

| Поле                                                                                                | Тип                | Правило                                                |
| --------------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------------------ |
| `title`                                                                                             | `string`           | Непустая строка.                                       |
| `ariaLabel`                                                                                         | `string`           | Необязательная подпись карусели; по умолчанию `title`. |
| `eyebrow`, `description`                                                                            | `string`           | Необязательные тексты.                                 |
| `offers`                                                                                            | `array \| object`  | Хотя бы одно корректное предложение.                   |
| `offers[].title`, `offers[].url`, `offers[].ctaLabel`, `offers[].image.url`                         | `string`           | Непустые строки.                                       |
| `offers[].image.alt`, `offers[].subtitle`, `offers[].legalText`, `offers[].id`, `offers[].position` | `string \| number` | Необязательные поля; alt по умолчанию title.           |
| `offers[].endsAt`                                                                                   | `string`           | Необязательная ISO дата-время с часовым поясом.        |

Некорректные предложения пропускаются; без корректных предложений элемент не рендерится.
