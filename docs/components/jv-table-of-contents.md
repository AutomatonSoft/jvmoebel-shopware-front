# `jv-table-of-contents`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Оглавление, которое прокручивает страницу к указанным разделам статьи.

## Настройка в Shopware

| Поле            | Где отображается                        | Обязательно |
| --------------- | --------------------------------------- | ----------- |
| Заголовок       | Заголовок оглавления                    | Да          |
| Название пункта | Текст ссылки в оглавлении               | Да          |
| ID якоря        | Раздел страницы, к которому ведёт пункт | Да          |
| Порядок         | Нумерация и последовательность пунктов  | Нет         |

`ID якоря` должен совпадать с HTML `id` целевого заголовка или блока на этой же странице.

## Технический контракт Shopware

- `slot.type`: `jv-table-of-contents`; данные передаются в `slot.data`.

| Поле                                | Тип                | Правило                                                                       |
| ----------------------------------- | ------------------ | ----------------------------------------------------------------------------- |
| `title`                             | `string`           | Непустая строка.                                                              |
| `items`                             | `array \| object`  | Хотя бы один корректный пункт.                                                |
| `items[].label`, `items[].anchorId` | `string`           | Непустые строки.                                                              |
| `items[].anchorId`                  | `string`           | Валидный HTML id: начинается с буквы, затем буквы, цифры, `_`, `:`, `.`, `-`. |
| `items[].id`, `items[].position`    | `string \| number` | Необязательны; position задаёт порядок.                                       |

Некорректные пункты пропускаются; без корректных пунктов элемент не рендерится.
