# `jv-editorial-team-grid`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Сетка карточек редакционной команды с фотографиями и ссылками на персональные страницы.

## Настройка в Shopware

| Поле             | Где отображается              | Обязательно |
| ---------------- | ----------------------------- | ----------- |
| Заголовок        | Над сеткой                    | Да          |
| Имя              | Заголовок карточки сотрудника | Да          |
| Роль             | Текст под именем              | Да          |
| Фото и alt-текст | Изображение карточки          | Да          |
| Ссылка           | Карточка сотрудника целиком   | Да          |
| Порядок          | Последовательность карточек   | Нет         |

## Технический контракт Shopware

- `slot.type`: `jv-editorial-team-grid`; данные передаются в `slot.data`.

| Поле                                                        | Тип                | Правило                                                       |
| ----------------------------------------------------------- | ------------------ | ------------------------------------------------------------- |
| `title`                                                     | `string`           | Непустая строка.                                              |
| `members`                                                   | `array \| object`  | Хотя бы один корректный участник.                             |
| `members[].name`, `members[].role`, `members[].url`         | `string`           | Непустые строки.                                              |
| `members[].image.url`                                       | `string`           | Непустой публичный URL.                                       |
| `members[].image.alt`, `members[].id`, `members[].position` | `string \| number` | Необязательны; alt по умолчанию имя, position задаёт порядок. |

Некорректные карточки пропускаются; без корректных участников элемент не рендерится.
