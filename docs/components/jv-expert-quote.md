# `jv-expert-quote`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Выделенная цитата эксперта с подписью.

## Настройка в Shopware

| Поле        | Где отображается       | Обязательно |
| ----------- | ---------------------- | ----------- |
| Цитата      | Основной крупный текст | Да          |
| Имя автора  | Под цитатой            | Да          |
| Роль автора | Рядом с именем         | Да          |

## Технический контракт Shopware

- `slot.type`: `jv-expert-quote`; данные передаются в `slot.data`.

| Поле                                | Тип      | Правило                        |
| ----------------------------------- | -------- | ------------------------------ |
| `quote`, `authorName`, `authorRole` | `string` | Каждое поле — непустая строка. |

При отсутствии любого поля элемент не рендерится.
