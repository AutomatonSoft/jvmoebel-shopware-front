# `sidebar-filter`

## Скриншот

> Добавьте сюда скриншот компонента из Shopware.

## Назначение

Стандартный слот боковых фильтров Shopware. В текущей витрине он не выводит интерфейс и служит только для совместимости с CMS-layout.

## Настройка в Shopware

У элемента нет полей. Его можно оставить в sidebar-layout категории, но посетитель не увидит отдельный блок фильтров от этого CMS-элемента.

## Технический контракт Shopware

- `slot.type`: `sidebar-filter`.
- `slot.data` и `slot.config` не используются.
- Компонент всегда возвращает `null`; данные из Shopware ему не требуются.
