# Глобальный Виджет Контактов (Contact Widget)

## Назначение

Плавающий виджет контактов ("кнопка связи"), который всегда фиксируется поверх всех страниц в нижнем правом углу экрана.
По клику разворачивается в меню, предлагающее пользователю список способов связи с магазином.
Так как этот виджет должен отображаться на **всех** страницах магазина без перезагрузки своего состояния, он выведен из системы блоков CMS (Shopping Experiences) и перенесен в **Глобальную конфигурацию магазина (Storefront Config)**, напрямую загружаясь в Footer Layout.

## Как настроить со стороны Shopware (Бэкенд)

Вместо создания CMS-блока, бекенд-разработчику необходимо расширить глобальный конфигурационный ответ API (Endpoint: `/storefront-config`), добавив объект `contactWidget` внутрь узла `footer`.

Ожидаемая JSON-структура от Shopware:

```json
{
  "footer": {
    "contactWidget": {
      "channels": [
        {
          "type": "telegram",
          "url": "https://t.me/XLANDJV",
          "label": "Telegram",
          "id": "telegram-1"
        },
        {
          "type": "whatsapp",
          "url": "https://wa.me/491512...",
          "label": "WhatsApp",
          "id": "wa-1"
        },
        {
          "type": "custom",
          "url": "https://vk.com/example",
          "label": "ВКонтакте",
          "icon": {
            "url": "https://cdn.jvmoebel.ch/icon.png"
          }
        }
      ]
    }
    // ... другие настройки футера
  }
}
```

### Поля объекта канала связи:

| Поле    | Тип                                                | Обязательно | Описание                                                                                                                                                |
| ------- | -------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `url`   | `string`                                           | Да          | Обязательное поле со ссылкой (поддерживаются протоколы `http`, `https`, `mailto:`, `tel:`, `sms:`).                                                     |
| `type`  | `telegram \| whatsapp \| email \| phone \| custom` | Нет         | Для типов `telegram`, `whatsapp`, `email` и `phone` встроены оптимизированные векторные иконки.                                                         |
| `label` | `string`                                           | Нет         | Подсказка (tooltip), всплывающая слева при наведении мышью.                                                                                             |
| `icon`  | `object`                                           | Нет         | Если администратор загружает кастомную картинку через медиа-менеджер, передайте объект с полем `url`. Эта картинка приоритетнее встроенных типа `type`. |
| `id`    | `string`                                           | Нет         | Уникальный ключ. Генерируется автоматически на фронтенде, если отсутствует.                                                                             |

## Технические особенности

- Компонент вызывается в `src/features/storefront-shell/components/store-footer.tsx`.
- Парсинг конфигурации происходит в `parseShopwareStorefrontConfig` (`src/integrations/shopware/mappers/storefront-config.ts`).
- При переходе по страницам виджет не перемонтируется благодаря React Layouts (состояние открытого/закрытого списка сохраняется и не моргает).
