# Video Shop page

## Route

`/video-shop`

## Composition

The mock page contains a `jv-page-header` followed by the ten YouTube videos
from the existing JVMöbel Video Shop. The videos use Shopware's standard
`youtube-video` CMS element and appear in a responsive two-column grid.

In live mode, the shared storefront router resolves the Shopware landing page
from its SEO URL. Editors can add, remove, and reorder standard YouTube video
blocks in Shopware Administration without changing the frontend. The Shopping
Experience controls their block and section layout.

The footer service navigation exposes the page as **Video Shop**.
